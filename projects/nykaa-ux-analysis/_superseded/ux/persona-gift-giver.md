# User experience — Gift giver (Rahul)

**Who:** Rahul, 32. Buying a birthday gift. Budget about **₹2,000–₹5,000**.

**Job (simple):** “I want a gift that looks premium, so I don’t look cheap.”

**Scenario we ran:** `gift-luxury`
**Platform:** Desktop site, logged in (4 Sep 2026).

**Screenshot:** `screenshots/good/gift-most-gifted-sets.png`

---

## What he did

1. Opened home (same sale banners as everyone else).
2. Searched: **luxury skincare gift set**.
3. Saw **91** results — much smaller than the 696 moisturizer list.
4. Cards showed **BESTSELLER** and **MOST GIFTED**.
5. Examples: Sol de Janeiro set **₹3650** (ad), Laneige set **₹1960**, Kimirica set **₹1557**.
6. Bag / pay page did **not** load.

---

## How it felt

| Feeling | What happened |
|---------|----------------|
| **Smooth** | Search matches “gift set”. Photos look giftable. “Most Gifted” helps a man who is unsure. |
| **Confusing** | Mix of prices: ₹1557 is a bit **below** his ₹2K floor; ₹3650 ad is inside budget but is still an ad. |
| **Slow** | Not really — results came fast. |
| **Frustrating** | Could not check **delivery date** or **gift wrap** because cart never opened. |

---

## Buy / cart / checkout / reorder — did we test this?

| Step | Did we try? | What we saw |
|------|-------------|-------------|
| **Buy** | Tried add-to-bag from the list. | No confirmation toast on desktop. |
| **Cart** | Opened bag URL. | Blank. **No gift wrap / ETA.** |
| **Checkout** | Planned. **Not seen.** | — |
| **Reorder** | No. This is a one-time gift. | — |

**Simple takeaway:** **Finding** a gift looks better than finding a “dry + sensitive + cheap” cream. **Paying** was not tested.

---

## What this means (PM class)

Same website, different job. Gift search is closer to a **small, curated shelf**. Skincare-concern search is a **warehouse**.

**One number to watch:** gift-set searches → add to bag, and average order value on those sessions.
