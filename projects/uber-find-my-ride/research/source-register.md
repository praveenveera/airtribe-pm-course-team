# Source Register

**Last updated:** 16 September 2026

The register records what each source can support and what it cannot support. “Primary” means the source directly owns the rule, product, or dataset being described; it does not mean the source independently proves user value.

- Telangana's current aggregator-guideline implementation
- Location-specific Uber feature availability in the live Hyderabad app
- Reliable Hyderabad four-wheel trip volume and issue-rate data
- Systematic coding of recent public reviews by problem type
- Evidence from drivers, security staff, venue operators, and people with accessibility needs
