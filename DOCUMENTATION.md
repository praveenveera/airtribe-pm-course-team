# Documentation

Repository-wide guidance lives here. Project-specific instructions remain inside each assignment or activity.

## Conventions

- Keep the original assignment or case brief close to the work.
- State the user, job, decision, and success measure.
- Separate observation, fact, interpretation, hypothesis, recommendation, and unknown.
- Record research dates and limitations.
- Preserve superseded work only when it helps explain how the thinking changed.
- Link the active submission from the project README.

Before publishing new material, use the root-level [public-sharing checklist](PUBLIC_SHARING_CHECKLIST.md).
