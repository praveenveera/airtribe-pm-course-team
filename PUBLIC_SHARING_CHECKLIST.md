# Public-sharing checklist

Use this checklist before committing material to this public repository.

## Privacy and access

- [ ] No passwords, tokens, cookies, authenticated browser state, or `.env` files
- [ ] No participant, customer, employer, account, ticket, or order identifiers
- [ ] Screenshots do not reveal names, email addresses, phone numbers, addresses, or payment details
- [ ] Document properties and comments contain only information intended to be public

## Evidence

- [ ] The research cut-off is visible
- [ ] External claims have a source and date
- [ ] Vendor claims are labelled as vendor claims
- [ ] Interviews are anonymized and consent boundaries are respected
- [ ] Hypotheses and recommendations are not presented as validated facts

## Submission quality

- [ ] The README links to the active version
- [ ] Generated PDF or slide artifacts were visually checked
- [ ] Superseded versions are clearly marked
- [ ] Links work without private accounts or local file paths
- [ ] Large generated folders and dependencies are ignored
